# 封面作图要点

出图前读本文件。流程见 `cover/AGENTS.md`。

一 `id` 出**一张大图**。不管小图。最终入库必须是 **900×383**（比例 900/383 ≈ **2.35:1**）。

**出图强制**：用**豆包 Seedream**（优先 4.5）在「新对话」里直出横版封面。  
**禁止**再用 `GenerateImage` / 16:9 蒙版裁切出封面。

---

## 一、通用要求（尺寸 / 底线）

### 成品

- **唯一合格尺寸**：**900×383**（约 2.35:1 横图）。
- 流程：提示词写死约 2.35:1 → 高清下载 → **一律**跑 `node scripts/crop-cover-235.mjs cover/images/<id>.jpg`。
  - 已是 900×383 → 脚本整段跳过
  - 比例已约 2.35:1（豆包常见大图）→ **不裁构图**，只压到 900×383
  - 比例差太多（其他模型 16:9 等）→ 居中裁再压

### 豆包出图参数（写进提示词）

在提示词正文里写死：

- `比例 2.35:1，成品像素 900×383，横版封面，无水印`
- `只出 1 张终稿，不要中间稿、不要多图拼版`
- 画面文字用**简体中文**；R 函数名按正文原样（如 `all.equal`、`save.image()`），禁止乱改成 `all_equal` 之类

豆包 UI 常没有「无水印」开关：提示词仍写无水印；若成图右下角仍有「豆包AI生成」，**可接受入库**（试批已确认观感够用），不要为抠水印反复空转。用户点名去水印再重做或裁边。

### 格式与忌项

- 成品 `jpg`；路径 `images/<id>.jpg`。
- 忌：假二维码 / 假头像墙；紫粉霓虹乱闪、玻璃拟态、乱粒子、假 3D 按钮条。
- 忌：代码墙 / 公式墙；小图拼版 / 虚线外框；钩子写错字 / 符号写丢（尤其 `==`、`.`、`()`）。

> 旧蒙版 `templates/ref-16x9-black235-white-margins.jpg` **已停用**，勿再引用。

## 二、本项目自定义（RPost · 缩略图钩子风）

> **B 站 / 油管 / 小红书缩略图**：大字钩子对准痛点、高对比、有冲突或前后对比。

### 要

1. **大字钩子**：对准**这篇正文**核心麻烦（短、响、可读）。
2. **高对比、色彩醒目**（暖橙 vs 青绿一类即可）。
3. **冲突或前后对比**（贴本篇场景，左右/前后都可）。
4. 插画 / 半写实 / 夸张比喻均可。

### 不要

- 单调静物当主视觉；代码墙 / 公式墙。
- **只看标题就出 prompt**。
- 小图拼版 / 虚线 / 外框；画面塞满重复小标签。

## 三、作图 prompt 怎么写（必读正文）

### 1. 先读推文

`content/posts/<id>/*.qmd`（或 `.md`）。勿只看 `title`。

### 2. 出图方式

| 项 | 约定 |
|----|------|
| 账号 | 豆包「迷城」（或指定小号） |
| 入口 | **新对话** + 「图像生成」（禁止「新工作任务→工作」） |
| 模型 | 尽量 Seedream 4.5 |
| 张数 | 每篇 **1** 个新对话、**1** 张终稿 |
| 下载 | 点开大图 →「保存」；或控制台 `EXPECT: 1` + `/workspace/bot-doubao/scripts/doubao-zip-download-hd.js`（只扫当前 `/chat/{id}`） |

### 3. prompt 必含

1. 尺寸与张数句（见上）。
2. 油管/B 站风，高对比。
3. **钩子原文**（与入库后肉眼核对一致）、冲突两边、主色、道具（均来自正文）。
4. 否定：无代码墙、无小图拼版、少重复标签；R 专名按正文。

### 4. 好例子

「比例 2.35:1，900×383，横版封面，无水印；只出 1 张终稿。油管缩略图。钩子『换电脑就挂？』。碎笔记本+dplyr 碎片 vs 挂锁锁 renv.lock。暖橙+青绿。无代码墙。函数名按原文。」

### 5. 出图后核验（写回前）

1. 尺寸已是 900×383。
2. 钩子可读，关键符号 / R 专名无明显写错（可接受轻微风格化，不可接受改义）。
3. 无色情 / 暴力 / 政治；无假二维码。
4. `cover.json` 的 `prompt` = 实际发给豆包的那条。

### 6. 写入 `cover.json` 的 `prompt`

存实际发给豆包的全文（须含 2.35:1 / 900×383）。
