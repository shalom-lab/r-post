# 封面作图要点

出图前读本文件。流程见 `cover/AGENTS.md`。

一 `id` 出**一张大图**。不管小图。最终入库必须是 **900×383**（比例 900/383 ≈ **2.35:1**）。

**出图强制**：用**豆包 Seedream**（优先 4.5）在「新对话」里直出横版封面；**不要**再用 `GenerateImage` 的 16:9 + 蒙版裁切流程。

---

## 一、通用要求（尺寸 / 底线）

### 成品

- **唯一合格尺寸**：**900×383**（约 2.35:1 横图）。
- 流程：**豆包提示词写死 2.35:1 / 900×383** → 高清下载 → 若原图更大，用 `node scripts/crop-cover-235.mjs`（或等价）压/裁成 900×383 覆盖。

### 豆包出图参数（写进提示词）

在提示词正文里写死：

- `比例 2.35:1，成品像素 900×383，横版封面，无水印`
- `只出 1 张终稿，不要中间稿、不要多图拼版`

豆包有时仍会出更大原图，落盘后再压到 900×383 最稳。

### 格式与忌项

- 成品 `jpg`；路径 `images/<id>.jpg`。
- 忌：假水印 / 假二维码 / 假头像墙；紫粉霓虹乱闪、玻璃拟态、乱粒子、假 3D 按钮条。
- 忌：代码墙 / 公式墙；小图拼版 / 虚线外框。

> 旧的 16:9 两色参考蒙版（`templates/ref-16x9-black235-white-margins.jpg`）**已停用**，仅作历史文件保留，新出图不要再引用。

---

## 二、本项目自定义（RPost · 缩略图钩子风）

> 非通用。**B 站 / 油管 / 小红书缩略图**：大字钩子对准痛点、高对比、有冲突或前后对比。

### 要

1. **大字钩子**：对准**这篇正文**核心麻烦。
2. **高对比、色彩醒目**。
3. **冲突或前后对比**（贴本篇场景）。
4. 插画 / 半写实 / 夸张比喻均可。

### 不要

- 单调静物当主视觉；代码墙 / 公式墙。
- **只看标题就出 prompt**。
- 小图拼版 / 虚线 / 外框。

---

## 三、作图 prompt 怎么写（必读正文）

### 1. 先读推文

`content/posts/<id>/*.qmd`（或 `.md`）。勿只看 `title`。

### 2. 出图方式

- 账号：豆包「迷城」（或指定小号）
- 入口：**新对话** + 开「图像生成」（不要「新工作任务→工作」）
- 模型：尽量 Seedream 4.5
- 高清：点开大图下载；或控制台 `PREFIX` + `EXPECT: 1` 跑 `/workspace/bot-doubao/scripts/doubao-zip-download-hd.js`（只扫当前会话）

### 3. prompt 必含

1. 尺寸句：`比例 2.35:1，成品像素 900×383，横版封面，无水印；只出 1 张终稿。`
2. 油管/B 站风，高对比。
3. 钩子原文、冲突具体画面、主色、道具（贴正文）。
4. 否定：无水印、无代码墙、无小图拼版。

### 4. 好例子

「比例 2.35:1，900×383，横版封面，无水印；只出 1 张终稿。油管缩略图。钩子『换电脑就挂？』。碎笔记本+dplyr 碎片 vs 挂锁锁 renv.lock。暖橙+青绿。无代码墙、无水印。」

### 5. 写入 `cover.json` 的 `prompt`

存实际发给豆包的那条（须含 2.35:1 / 900×383）。
