# 封面作图要点

出图前读本文件。流程、清单、提交、以及「先构思 prompt」那一步，见 `cover/AGENTS.md`。

默认做**一张头条横图**（以后台实际上传为准）。

---

## 一、通用要求（尺寸 / 格式 / 底线）

与具体文章无关，每张图都遵守：

1. **尺寸**
   - 比例约 **2.35:1**，常用 **900×383**（可等比放大，比例不变）。
   - 主标题与主视觉放在画面**中央约正方形安全区**，列表裁成方图时左右不易被切没。
2. **格式**
   - `jpg` / `png` / `webp`，体积适中，便于公众号上传。
   - 成图路径相对 `cover/`（如 `images/<id>.jpg`）。
3. **字**
   - 少：短标题或关键词，清楚；也可以几乎没字，靠画面本身。
4. **忌**
   - 假水印、假二维码、假头像墙。
   - 紫粉霓虹、玻璃拟态、乱粒子、假 3D 按钮条等浓 AI 味。
   - 一两主色或自然光感 + 留白；像真人拍的或认真做的平面，不要像生成器默认皮肤。

---

## 二、本项目自定义（RPost / 与文章怎么挂钩）

在通用要求之上，本仓库封面的画面思路：

1. **可以先读文章**（标题、简介、正文场景），心里有个「这篇在干什么」——用来找感觉，不是为了把技术画满屏。
2. **不必墙贴技术主题**，也不必一眼看出「这是在讲 R」。
3. **联想、意会、类比**：生活里的事、真实实物、日常场景来暗示即可；不必画代码、终端、公式墙。
4. **没好思路就用风景 / 美图 / 氛围图**：好看、干净、耐看优先；和文章气质沾一点边就行，不强行塞技术符号。
5. **和文章的关系**

| 可以 | 不必 |
|------|------|
| 参考内容找感觉、找类比 | 画面必须画满「宽表→长表」之类技术示意 |
| 实物、风景、日常场景意会 | 一眼必须猜到讲哪个 R 函数 |
| 美图撑场，气质沾边就行 | 为贴题硬塞表格 / 终端 / 代码块 |

`prompt` 里只写**本次实际画面**（构图、色调、主体、画面上的字），不要把本文件整段抄进去。
