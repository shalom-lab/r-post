分析做到一半：表洗完了要留着明天接着跑，同事催一版能打开的表，或者快下班了想先把现场按住。这时别背「有几种保存函数」，对着眼前这一步挑一个够用的写法就行。

下面用 `mtcars` 里 6 行演示，文件都进临时目录，不在项目里留垃圾。

``` r
cars <- mtcars[1:6, c("mpg", "cyl", "wt")]
demo_dir <- tempdir()
```

## RDS：清洗完，明天接着跑

单个数据框、模型或列表，还要原样进脚本：用
RDS。结构跟着走，读回来时对象叫什么由你定。

``` r
saveRDS(cars, file.path(demo_dir, "cars.rds"))
cars_rds <- readRDS(file.path(demo_dir, "cars.rds"))
cars_rds
```

                       mpg cyl    wt
    Mazda RX4         21.0   6 2.620
    Mazda RX4 Wag     21.0   6 2.875
    Datsun 710        22.8   4 2.320
    Hornet 4 Drive    21.4   6 3.215
    Hornet Sportabout 18.7   8 3.440
    Valiant           18.1   6 3.460

中间结果、流水线里反复读写同一个对象，先想到它就行。

## Excel：同事要能直接打开的表

对方习惯 Excel、只要表格内容：用 `writexl::write_xlsx()`，写出就能打开。

``` r
excel_file <- file.path(demo_dir, "cars.xlsx")
writexl::write_xlsx(cars, excel_file)
file.exists(excel_file)
```

    [1] TRUE

`TRUE` 表示文件已写出。模型、列表这类复杂对象别硬塞进 xlsx。

## CSV：还要给别的工具读

表要进 Python、数据库导入，或对方没有 Excel：走 CSV，通用交换最省事。

``` r
csv_file <- file.path(demo_dir, "cars.csv")
write.csv(cars, csv_file, row.names = FALSE)
read.csv(csv_file)
```

       mpg cyl    wt
    1 21.0   6 2.620
    2 21.0   6 2.875
    3 22.8   4 2.320
    4 21.4   6 3.215
    5 18.7   8 3.440
    6 18.1   6 3.460

记得加
`row.names = FALSE`，否则行名会多占一列。中文路径或内容若乱码，读写时显式设
`fileEncoding`（或新接口的
`encoding`）再核对。日期、因子读回去后最好再看一眼类型。

表已经很大、或要跨语言长期交换时，可以以后再上
parquet；日常中途落盘，CSV / RDS 通常够用。

## save()：几个相关对象装进同一个文件

清洗表和拟合结果要一起带走：用 `save()` 点名写入 `.RData`。`load()`
时**按原来的名字**回来，环境里若已有同名对象会被盖掉。

``` r
cars_fit <- lm(mpg ~ wt, data = cars)
rdata_file <- file.path(demo_dir, "cars.RData")
save(cars, cars_fit, file = rdata_file)

# 演示：清掉这两个名字再 load，看它们怎么回来
rm(cars, cars_fit)
load(rdata_file)
cars
```

`load()`
的返回值是恢复出来的对象名字符向量；真正用的是副作用——对象直接进当前环境。只要一个对象、还想读回来改名时，仍更常用
RDS。

## save.image()：临时中断，先拍张快照

临时离开、还没整理完要存什么：可以用 `save.image()`
给**整个工作区**拍一张（当前环境里几乎所有对象，不只是上面的 `cars`）。

``` r
workspace_file <- file.path(demo_dir, "workspace.RData")
save.image(file = workspace_file)
file.exists(workspace_file)
```

    [1] TRUE

它像应急备份，不是日常习惯。正式项目里优先留完整脚本，再按需 `saveRDS` /
`save()`；工作区越存越脏，复现会变难。

中途落盘时对照场景挑一个就够：续跑用 RDS，给 Excel 同事用 xlsx，跨工具用
CSV，多对象用 `save()`，整现场应急才动 `save.image()`。
