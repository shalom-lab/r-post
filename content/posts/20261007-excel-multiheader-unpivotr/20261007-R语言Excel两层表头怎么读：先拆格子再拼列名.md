# R语言Excel两层表头怎么读：先拆格子再拼列名
RPost
2026-10-07

门诊导出常把「基线 / 随访」写在第一行，下面一行才是收缩压、舒张压。Excel
里组名合并了两格，读进 R 后合并格只剩左上有字，右边是 `NA`。`readxl`
直接读成宽表时，列名对不上，后面难做差值。

下面不碰真实 xlsx，在内存里造一张同形状的脏表，用 `unpivotr`
拆格子再拼。依赖：`unpivotr`、`dplyr`、`tidyr`。

## 内存里的两层表头

第一行是组，空位表示合并单元格；第二行是指标；再往下是人：

``` r
raw <- data.frame(
  V1 = c(NA, "编号", "1", "2", "3"),
  V2 = c("基线", "收缩压", "120", "130", "118"),
  V3 = c(NA, "舒张压", "80", "85", "76"),
  V4 = c("随访", "收缩压", "118", "128", "115"),
  V5 = c(NA, "舒张压", "78", "82", "74"),
  stringsAsFactors = FALSE
)
raw
```

        V1     V2     V3     V4     V5
    1 <NA>   基线   <NA>   随访   <NA>
    2 编号 收缩压 舒张压 收缩压 舒张压
    3    1    120     80    118     78
    4    2    130     85    128     82
    5    3    118     76    115     74

`V3`、`V5` 第一行是 `NA`，对应 Excel 里「基线」「随访」合并后的空格。

## 先拆成格子，再取表头

`as_cells()`
把每个格子变成一行，带上行号、列号和内容。`behead("up-left", group)`
按「左上方」认组合并格；再向上取指标、向左取编号：

``` r
library(unpivotr)
library(dplyr)

raw |>
  as_cells() |>
  behead("up-left", group) |>
  behead("up", measure) |>
  behead("left", id) |>
  transmute(
    id,
    group,
    measure,
    value = as.numeric(chr)
  )
```

每人每组每个指标一行。空着的合并格不必先手填：`up-left` 会把 `V3`
归到「基线」、`V5` 归到「随访」。

若更习惯先填空再取表头，可对表头行用
`tidyr::fill(..., .direction = "right")` 把 `NA` 按行补上，再两次
`behead("up", ...)`。合并方向对得上时，两种写法结果一致。

## 和宽转长的分工

列名已经是 `基线_收缩压` 这种单层名字时，用 `tidyr::pivot_longer()`
即可，见
[随访宽表怎么转成长表](./r-post/article/20260927-wide-to-long)。两层表头、还带着合并空位时，先
`as_cells` + `behead` 把组名和指标拆开，再进入普通长表分析。
