# 啥是正则表达式？为啥字符串处理很关键？
RPost
2026-09-21

正则表达式可以理解成一套“描述文本规律”的写法。你不必先背完所有符号，遇到一批文件名、编码或固定格式文本时，再用它找出共同规律就行。

下面看三个实际场景。每个场景只多学一点语法。

## 场景 1：读入所有以 dataset 开头的 xlsx 文件

假设 data 文件夹里混着很多文件，我们只要 dataset\_ 开头、.xlsx
结尾的文件。这里的 ^ 表示开头，\$
表示结尾；点号在正则里有特殊含义，所以写成 \\

``` r
xlsx_files <- list.files(
  "data",
  pattern = "^dataset.*\\.xlsx$",
  full.names = TRUE
)

basename(xlsx_files)
```

    character(0)

找到文件后，可以配合 for 循环逐个读入。用列表保存结果，是因为每个 Excel
文件可能有不同的行数。

``` r
data_list <- vector("list", length(xlsx_files))
names(data_list) <- basename(xlsx_files)

for (i in seq_along(xlsx_files)) {
  data_list[[i]] <- readxl::read_excel(xlsx_files[i])
}
```

如果目录里没有匹配文件，seq_along()
会得到空序列，循环不会报错。正式处理前，可以再用 length(xlsx_files)
核对找到几个文件。

## 场景 2：根据 ICD 编码识别呼吸系统感染

ICD 编码也是有结构的文本。下面用一组最小示例，识别常见的
J00–J06、J09–J18 和 J20–J22 范围。

``` r
icd <- c("J06.9", "J18.9", "J45.9", "A09", "U07.1")
infection_pattern <- "^J(0[0-6]|09|1[0-8]|2[0-2])"

is_respiratory_infection <- grepl(infection_pattern, icd)
data.frame(icd, is_respiratory_infection)
```

        icd is_respiratory_infection
    1 J06.9                     TRUE
    2 J18.9                     TRUE
    3 J45.9                    FALSE
    4   A09                    FALSE
    5 U07.1                    FALSE

括号中的 \| 表示“或者”。J45.9
属于呼吸系统疾病，但不在这里定义的感染范围内，所以结果为 FALSE。

这段规则只适合演示字符串识别。真实医疗数据要以正在使用的 ICD
版本和业务编码表为准，例如 U07.1
这类编码需要另行纳入，不能只靠一个正则完成临床分类。

## 场景 3：从固定格式文本中抠出字段

再看一类常见文本：每行都按 ID\|DATE\|VALUE
排列。括号可以把想要的部分分别“抓住”，\[^\|\]+
表示连续读取一个或多个非竖线字符。

``` r
text <- c(
  "ID=PT001|DATE=2026-09-20|VALUE=87",
  "ID=PT002|DATE=2026-09-21|VALUE=92"
)

pattern <- "^ID=([^|]+)\\|DATE=([^|]+)\\|VALUE=([^|]+)$"
parts <- regmatches(text, regexec(pattern, text))

fields <- do.call(rbind, lapply(parts, function(x) x[-1]))
colnames(fields) <- c("id", "date", "value")
fields
```

         id      date         value
    [1,] "PT001" "2026-09-20" "87" 
    [2,] "PT002" "2026-09-21" "92" 

regexec() 负责定位整段文本和三个捕获组，regmatches()
再把内容取出来。x\[-1\] 去掉完整匹配，只保留三个字段。

正则表达式的价值就在这里：先描述文本的共同结构，再让 R
批量筛选、判断或提取。先从 ^、\$、.、\*、括号和 \|
这些常用符号开始，已经能处理很多真实任务。
