## 备注里搜关键词

导出备注写得很随意，你只想先标出带「缺测 / 待核 /
异常」的行，方便人工回看。

``` r
notes <- c(
  "血压缺测，次日补录",
  "指标正常，按原方案",
  "数值异常，待核对方库",
  "已复核，无修改"
)

keywords <- c("缺测", "待核", "异常")
kw_pattern <- paste(keywords, collapse = "|")

hit <- grepl(kw_pattern, notes)
data.frame(notes, hit)
```

                     notes   hit
    1   血压缺测，次日补录  TRUE
    2   指标正常，按原方案 FALSE
    3 数值异常，待核对方库  TRUE
    4       已复核，无修改 FALSE

`grepl()` 得到逻辑向量，可直接筛选。词会改，就改 `keywords` 向量，再用
`paste(..., collapse = "|")` 拼。

只要精确字面、不要通配时，用 `fixed = TRUE`：

``` r
grepl("缺测|待核", notes[1], fixed = TRUE)  # 字面整串，| 不再表示「或者」
```

    [1] FALSE

``` r
grepl("缺测|待核", notes[1])                # 正则：缺测 或 待核
```

    [1] TRUE

英文词表还要小心假阳性：`grepl("cat", "category")` 为
`TRUE`。需要整词时再加边界 `\b`；中文日常词表通常直接 `|` 就够。

## 从文件名抠地区和日期

批量文件经常长这样：`sales_华东_202409.xlsx`。表还没读，先从文件名把地区、年月拿出来，后面好分组、好核对。

``` r
files <- c(
  "sales_华东_202409.xlsx",
  "sales_华北_202410.xlsx",
  "sales_华南_202411.xlsx",
  "readme.txt"
)

# 只要 xlsx；捕获「地区」和「6 位年月」
file_pat <- "^sales_(.+)_(20[0-9]{4})\\.xlsx$"
matched <- regmatches(files, regexec(file_pat, files))

# 先看第一条：整串 + 两个捕获组
matched[[1]]
```

    [1] "sales_华东_202409.xlsx" "华东"                   "202409"                

`matched[[1]]` 的第 1
个元素是整段匹配，后面才是括号里抓住的字段。对不上的（如
`readme.txt`）长度为 0：

``` r
matched[[4]]
```

    character(0)

``` r
length(matched[[4]])  # 0 → 无匹配
```

    [1] 0

收成数据框时，无匹配写成 `NA`：

``` r
file_info <- do.call(
  rbind,
  lapply(seq_along(matched), function(i) {
    x <- matched[[i]]
    if (length(x) < 3) {
      return(data.frame(
        file = files[i],
        region = NA_character_,
        yyyymm = NA_character_,
        stringsAsFactors = FALSE
      ))
    }
    data.frame(
      file = x[1],
      region = x[2],
      yyyymm = x[3],
      stringsAsFactors = FALSE
    )
  })
)

file_info
```

                        file region yyyymm
    1 sales_华东_202409.xlsx   华东 202409
    2 sales_华北_202410.xlsx   华北 202410
    3 sales_华南_202411.xlsx   华南 202411
    4             readme.txt   <NA>   <NA>

`readme.txt` 对不上模式，就是 `NA`，正好当过滤。真活里把 `sales_`
前缀、日期位数换成你们的命名规则即可。

## 从规则串里抠字段

配置有时整段塞在一列里，例如 `FIELD=体温|OP=>=|VALUE=37.5|UNIT=C`。与其
`substr` 数位置，不如用捕获组按段取出。

``` r
rules <- c(
  "FIELD=体温|OP=>=|VALUE=37.5|UNIT=C",
  "FIELD=血氧|OP=<|VALUE=93|UNIT=%",
  "坏掉的一行没有竖线"
)

rule_pat <- "^FIELD=([^|]+)\\|OP=([^|]+)\\|VALUE=([^|]+)\\|UNIT=([^|]+)$"
matched <- regmatches(rules, regexec(rule_pat, rules))

matched[[1]]  # 整串 + 四个捕获组
```

    [1] "FIELD=体温|OP=>=|VALUE=37.5|UNIT=C" "体温"                              
    [3] ">="                                 "37.5"                              
    [5] "C"                                 

``` r
matched[[3]]  # 长度 0，失败例
```

    character(0)

`([^|]+)` 表示「一段不含 `|` 的内容」。收表时同样把失败行写成 `NA`：

``` r
rule_df <- do.call(
  rbind,
  lapply(matched, function(x) {
    if (length(x) < 5) {
      return(data.frame(
        field = NA_character_,
        op = NA_character_,
        value = NA_character_,
        unit = NA_character_,
        stringsAsFactors = FALSE
      ))
    }
    data.frame(
      field = x[2],
      op = x[3],
      value = x[4],
      unit = x[5],
      stringsAsFactors = FALSE
    )
  })
)

rule_df
```

      field   op value unit
    1  体温   >=  37.5    C
    2  血氧    <    93    %
    3  <NA> <NA>  <NA> <NA>

关键词表、文件名模板、规则格式都会变：把可变部分留在数据或配置里，正则只写死结构。对不上就给
`NA`，别假设每次都扣得出来。
