# 啥是正则表达式？先会认文本形状
RPost
2026-09-21

清洗病历备注、随访导出时，总有一列文字看着乱，其实藏着同一套形状：文件名都是
`随访_地区_年月.xlsx`，病程里偶发「发热」「高烧」，检验标签
`血常规-白细胞` 要改成 `白细胞（血常规）` 这类写法。

**正则表达式**就是用一小段文字去描述这种形状。这一段叫
**pattern（模式）**：你告诉 R「我想找的长什么样」，R
再去字符向量里认、筛、改。不必先背全表符号；先会认形状，就会用一半。

本文只讲「认」和「筛」；要从字符串里**提取**地区、日期、字段值，看同系列的提取数据篇。

## 场景 1：在文件名向量里筛出目标表

实际整理数据时，常常先拿到一串文件名（或 `list.files()`
的结果）。这里直接用字符向量演示：只要 `随访_` 开头、`.xlsx` 结尾的。

``` r
files <- c(
  "随访_华东_202409.xlsx",
  "随访_华北_202410.xlsx",
  "readme.txt",
  "随访_backup.csv",
  "病例_备注.xlsx"
)

# ^ 开头，$ 结尾；点号在正则里是「任意字符」，所以写成 \\.
files[grepl("^随访_.*\\.xlsx$", files)]
```

    [1] "随访_华东_202409.xlsx" "随访_华北_202410.xlsx"

`grepl(pattern, x)` 对每个元素返回 `TRUE` / `FALSE`。`.*`
表示中间随便多长。文件名规则变了，只改 pattern，不必手写一堆
`startsWith` / `endsWith`。

## 场景 2：病程备注里有没有发热相关词

随访导出的主诉/病程写得很随意，你只想先标出带「发热 / 发烧 / 高烧 / 低热
/ 烧」一类说法的行。词表要不要带单字「烧」，并排比一下就知道：

``` r
notes <- c(
  "主诉发热三天，伴干咳",
  "术后恢复可，切口干燥",
  "昨晚又烧到38.5℃，已物理降温",
  "偶有烧心，与进食相关",
  "左手烧伤，换药中",
  "病程平稳，否认发热"
)

keywords <- c("发热", "发烧", "高烧", "低热", "烧")
data.frame(notes,
  loose  = grepl(paste(keywords, collapse = "|"), notes),
  strict = grepl("发热|发烧|高烧|低热", notes))
```

                            notes loose strict
    1        主诉发热三天，伴干咳  TRUE   TRUE
    2        术后恢复可，切口干燥 FALSE  FALSE
    3 昨晚又烧到38.5℃，已物理降温  TRUE  FALSE
    4        偶有烧心，与进食相关  TRUE  FALSE
    5            左手烧伤，换药中  TRUE  FALSE
    6          病程平稳，否认发热  TRUE   TRUE

`|` 表示「或者」：词表拼成一条 pattern，命中其中任一就算。词表会改，就改
`keywords`，再用 `paste(..., collapse = "|")` 拼，比手改正则正文稳。

看 `loose`
这一列：「偶有烧心」那行是假阳性，单字「烧」把胃里的烧心也算进来了；「左手烧伤」同理。可要是图省事把「烧」删掉，`strict`
又漏了「昨晚又烧到38.5℃」这种口语写法。想两头都顾，可以用 `perl = TRUE`
写「后面不跟心、伤的烧」：

``` r
grepl("发热|低热|烧(?!心|伤)", notes, perl = TRUE)
```

    [1]  TRUE FALSE  TRUE FALSE FALSE  TRUE

最后一行「否认发热」在两列里都是
`TRUE`。关键词只适合做第一遍粗筛，「否认发热」「无发热」照样命中，是不是真发热还得看上下文。

英文关键词要注意边界：`grepl("cat", "category")`
也会命中，需要整词时再学 `\b`。只要精确字面、不要正则功能时，加
`fixed = TRUE`。体温录成了「37,5」，按默认正则去找「37.5」也会命中，因为点号能对上任意一个字符，逗号也算：

``` r
grepl("37.5", "体温37,5℃")
```

    [1] TRUE

``` r
grepl("37.5", "体温37,5℃", fixed = TRUE)
```

    [1] FALSE

## 场景 3：用捕获组做一次简单替换

有时要改的是写法，不用筛行：检验标签 `血常规-白细胞` 想改成
`白细胞（血常规）`。括号 `()` 能把匹配到的片段「抓住」，替换时用
`\\1`、`\\2` 再拼回去。

``` r
labels <- c("血常规-白细胞", "血常规-血红蛋白", "生化-肌酐", "临时备注")

# (.+) 抓住横线左右两段；\\2、\\1 调换顺序
sub("^(.+)-(.+)$", "\\2（\\1）", labels)
```

    [1] "白细胞（血常规）"   "血红蛋白（血常规）" "肌酐（生化）"      
    [4] "临时备注"          

对不上模式的（如「临时备注」）原样留下，`sub()`
不会报错。要全局替换同一串里的多处，用 `gsub()`；只改第一次，用
`sub()`。
