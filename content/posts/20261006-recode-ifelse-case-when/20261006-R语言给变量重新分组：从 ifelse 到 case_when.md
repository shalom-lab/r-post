# R语言给变量重新分组：从 ifelse 到 case_when
RPost
2026-10-06

体检表要交三列文字：BMI
分成四档，血压按收缩压和舒张压里更高的一档，性别从 1、2
改成男、女。行数少的时候，嵌套 `ifelse`
写得完。档一多，边界和缺失会标错，函数也不报错。

## BMI 切四档

国内成人常用切点，单位 kg/m²：偏瘦小于 18.5，正常从 18.5 到不到
24，超重从 24 到不到 28，肥胖大于等于 28。下面 8 个数带了切点
18.5、24、28，还有一个缺失。

``` r
bmi <- c(17.2, 18.5, 23.9, 24, 27.9, 28, 31.5, NA)
data.frame(
  bmi,
  low_first = ifelse(
    bmi >= 18.5, "正常",
    ifelse(bmi >= 24, "超重",
      ifelse(bmi >= 28, "肥胖", "偏瘦"))
  ),
  edge = ifelse(
    bmi <= 18.5, "偏瘦",
    ifelse(bmi < 24, "正常",
      ifelse(bmi < 28, "超重", "肥胖"))
  ),
  group = ifelse(
    bmi < 18.5, "偏瘦",
    ifelse(bmi < 24, "正常",
      ifelse(bmi < 28, "超重", "肥胖"))
  )
)
```

       bmi low_first edge group
    1 17.2      偏瘦 偏瘦  偏瘦
    2 18.5      正常 偏瘦  正常
    3 23.9      正常 正常  正常
    4 24.0      正常 超重  超重
    5 27.9      正常 超重  超重
    6 28.0      正常 肥胖  肥胖
    7 31.5      正常 肥胖  肥胖
    8   NA      <NA> <NA>  <NA>

`low_first` 把「大于等于 18.5」放在最外层。31.5
已经满足这一条，直接标成正常，里面两层用不上。这一列只有 17.2
是偏瘦，24、28 和 31.5 都标成正常，缺失是 NA。

`edge` 的顺序对了，18.5 却写成了 `<=`。切点是「18.5
起算正常」，这一格变成偏瘦。24 仍是超重，28 仍是肥胖。

`group` 从偏瘦写起，右端用小于。18.5 和 23.9 正常，24 和 27.9 超重，28
和 31.5 肥胖，17.2 偏瘦。三列的缺失都是 NA：`bmi < 18.5` 碰到缺失得到
NA，`ifelse` 就返回 NA，不会挑一档填上。

切点只是一串区间时，可以写
`cut(bmi, c(-Inf, 18.5, 24, 28, Inf), right = FALSE)`。`right = FALSE`
表示右边开着，24 进超重，28 进肥胖，和 `group`
一致。血压要同时看两列，`cut` 不够用。

## 阳性和数字 0 不能写进同一列

「阳性 / 没阳性」有人写成：条件成立就写「阳性」，否则留数字 0。依赖
`dplyr`。

``` r
library(dplyr)
flag <- c(TRUE, FALSE, TRUE)
ifelse(flag, "阳性", 0)
```

    [1] "阳性" "0"    "阳性"

``` r
tryCatch(
  if_else(flag, "阳性", 0),
  error = function(e) conditionMessage(e)
)
```

    [1] "Can't combine `true` <character> and `false` <double>."

``` r
if_else(flag, "阳性", "阴性")
```

    [1] "阳性" "阴性" "阳性"

`ifelse` 得到 `"阳性" "0" "阳性"`。中间的 0 变成字符 `"0"`，后面再按数字
0 去筛，对不上这一行。`dplyr::if_else`
要求两个结果类型相同，这里报错：一边是字符，一边是数字。两边都写成文字，才是阳性、阴性、阳性。

## 血压要同时看两列

成人门诊常用分级，单位
mmHg。两列不在同一档时取更高的一档：收缩压大于等于 180 或舒张压大于等于
110 是 3 级，大于等于 160 或 100 是 2 级，大于等于 140 或 90 是 1
级，大于等于 120 或 80 是正常高值，两边都更低是正常。

``` r
bp <- data.frame(
  id = 1:6,
  sbp = c(118, 128, 152, 138, 186, NA),
  dbp = c(76, 78, 88, 96, 100, 70)
)
bp |>
  mutate(low_first = case_when(
    sbp >= 120 | dbp >= 80 ~ "正常高值",
    sbp >= 140 | dbp >= 90 ~ "1级",
    sbp >= 160 | dbp >= 100 ~ "2级",
    sbp >= 180 | dbp >= 110 ~ "3级",
    TRUE ~ "正常"
  ))
```

      id sbp dbp low_first
    1  1 118  76      正常
    2  2 128  78  正常高值
    3  3 152  88  正常高值
    4  4 138  96  正常高值
    5  5 186 100  正常高值
    6  6  NA  70      正常

`case_when` 从上往下，第一条成立就停。120
写在最上面时，152/88、138/96、186/100 三行都是正常高值。186 已经够 3
级，但 `186 >= 120` 先成立，3 级那一行轮不到。

高档放前面。缺失单独写在第一行，不然 `.default` 会把「比较结果是
NA」收成正常。

``` r
bp |>
  mutate(
    swallowed = case_when(
      sbp >= 180 | dbp >= 110 ~ "3级",
      sbp >= 160 | dbp >= 100 ~ "2级",
      sbp >= 140 | dbp >= 90 ~ "1级",
      sbp >= 120 | dbp >= 80 ~ "正常高值",
      .default = "正常"
    ),
    grade = case_when(
      is.na(sbp) | is.na(dbp) ~ NA_character_,
      sbp >= 180 | dbp >= 110 ~ "3级",
      sbp >= 160 | dbp >= 100 ~ "2级",
      sbp >= 140 | dbp >= 90 ~ "1级",
      sbp >= 120 | dbp >= 80 ~ "正常高值",
      .default = "正常"
    )
  )
```

      id sbp dbp swallowed    grade
    1  1 118  76      正常     正常
    2  2 128  78  正常高值 正常高值
    3  3 152  88       1级      1级
    4  4 138  96       1级      1级
    5  5 186 100       3级      3级
    6  6  NA  70      正常     <NA>

第 6 人收缩压缺失、舒张压 70。`swallowed` 是正常：带 NA
的比较不算成立，最后进了 `.default`。`grade` 仍是 NA。第 4 人
138/96，收缩压只到正常高值，舒张压到 1 级，取 1 级。第 5 人 186/100 是 3
级。118/76 正常，128/78 正常高值，152/88 是 1 级。

## 1 和 2 改成男、女

没写进 `case_when` 的编码，结果是 NA。9
若表示拒答，不单独写，就和真缺失一样。

``` r
sex <- c(1, 2, 9, NA)
case_when(sex == 1 ~ "男", sex == 2 ~ "女")
```

    [1] "男" "女" NA   NA  

``` r
case_when(sex == 1 ~ "男", sex == 2 ~ "女", sex == 9 ~ "不详")
```

    [1] "男"   "女"   "不详" NA    

第一段是男、女、NA、NA。第二段把 9 写成不详，真缺失仍是 NA。

多档、还要看两列时，高档写在前面，缺失单独写成 NA，用 `case_when`。
