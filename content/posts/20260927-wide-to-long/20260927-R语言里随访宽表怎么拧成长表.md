# R 语言里随访宽表怎么拧成长表
RPost
2026-09-27

反复测量、三次随访、多时点导出——Excel
里往往一行一个人，`bp_v1`、`bp_v2`、`bp_v3`
横着排。做前后对比、画折线、按人次汇总时，要的是「一人多行」的长表。依赖：`tidyr`。

## 啥是宽表、啥是长表

宽表：同一人占一行，时点散在多列。

``` r
wide <- data.frame(
  id = c("A", "B"),
  bp_v1 = c(120, 118),
  bp_v2 = c(118, 116),
  bp_v3 = c(122, 115)
)
wide
```

      id bp_v1 bp_v2 bp_v3
    1  A   120   118   122
    2  B   118   116   115

长表：同一人占多行，时点一列、数值一列。

``` r
data.frame(
  id = rep(c("A", "B"), each = 3),
  visit = rep(c("v1", "v2", "v3"), 2),
  bp = c(120, 118, 122, 118, 116, 115)
)
```

      id visit  bp
    1  A    v1 120
    2  A    v2 118
    3  A    v3 122
    4  B    v1 118
    5  B    v2 116
    6  B    v3 115

导出给人看的对照表常是宽的；进模型、画图、按时点筛，长表更方便。下面用
`tidyr` 拧。

## 三次随访横着排，拧成长表

把 `bp_v1`–`bp_v3` 收成 `visit` + `bp`：

``` r
library(tidyr)

long_bp <- wide |>
  pivot_longer(
    cols = starts_with("bp_"),
    names_to = "visit",
    names_prefix = "bp_",
    values_to = "bp"
  )
long_bp
```

    # A tibble: 6 × 3
      id    visit    bp
      <chr> <chr> <dbl>
    1 A     v1      120
    2 A     v2      118
    3 A     v3      122
    4 B     v1      118
    5 B     v2      116
    6 B     v3      115

`cols` 选要拧的列；`names_to` 接原列名剥下来的标签；`names_prefix`
去掉前缀，只留 `v1` / `v2` / `v3`；`values_to` 接数值列名。`id`
这种不变列会自动留下。

坑：列名写错或漏选，多出来的宽列还在表里。拧完先看几行，核对行数。缺访列常是
`NA`：默认会留下这些行；若只想保留有实测的行，加
`values_drop_na = TRUE`。还要用的缺失记录会被一起删掉，删之前先确认。

## 多个指标一起拧

同一时点还有体重，列名像 `bp_v1`、`wt_v1`、`bp_v2`、`wt_v2`。用 `.value`
一次拧成「时点一列、各指标各一列」：

``` r
data.frame(
  id = c("A", "B"),
  bp_v1 = c(120, 118), wt_v1 = c(70, 65),
  bp_v2 = c(118, 116), wt_v2 = c(69, 64)
) |>
  pivot_longer(
    cols = -id,
    names_to = c(".value", "visit"),
    names_sep = "_"
  )
```

    # A tibble: 4 × 4
      id    visit    bp    wt
      <chr> <chr> <dbl> <dbl>
    1 A     v1      120    70
    2 A     v2      118    69
    3 B     v1      118    65
    4 B     v2      116    64

`names_to` 里的 `.value`
表示：下划线前半截当列名（`bp`、`wt`），后半截进 `visit`。结果是
`id | visit | bp | wt`，按行对齐血压和体重更方便。

列名不规则时，把 `names_sep` 换成 `names_pattern`，括号与 `names_to`
一一对应：

``` r
data.frame(
  id = c("A", "B"),
  bp_v1 = c(120, 118), wt_v1 = c(70, 65),
  bp_v2 = c(118, 116), wt_v2 = c(69, 64)
) |>
  pivot_longer(
    cols = -id,
    names_to = c(".value", "visit"),
    names_pattern = "(bp|wt)_(v\\d+)"
  )
```

    # A tibble: 4 × 4
      id    visit    bp    wt
      <chr> <chr> <dbl> <dbl>
    1 A     v1      120    70
    2 A     v2      118    69
    3 B     v1      118    65
    4 B     v2      116    64

附注：若真要把指标名和数值叠成两列（堆叠图、按指标汇总），再用
`names_to = c("measure", "visit")` +
`values_to = "value"`；日常多指标对齐，优先 `.value`。

## 长表再拧回宽表

汇报对照、按人一行贴回 Excel 时，再变宽：

``` r
long_bp |>
  pivot_wider(
    names_from = visit,
    values_from = bp,
    names_prefix = "bp_"
  )
```

    # A tibble: 2 × 4
      id    bp_v1 bp_v2 bp_v3
      <chr> <dbl> <dbl> <dbl>
    1 A       120   118   122
    2 B       118   116   115

`names_from` 决定新列名从哪来，`values_from`
填数值。一对多键对不齐时会报错或变成 list-col——合并、对照前确认 `id` +
时点能唯一定一行。

长宽来回就这几下：导出常见宽，分析先 `pivot_longer`；要对齐对照再
`pivot_wider`。列名规律摸清，半条命令够用。
