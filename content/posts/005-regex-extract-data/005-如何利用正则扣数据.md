# 如何利用正则扣数据
RPost
2026-09-27

清洗病案或监测数据时，常会碰到三种“扣数据”任务：一段自由文本里有没有呼吸道相关词；一列
ICD
里哪些算呼吸道感染；一条规则字符串里把阈值、字段名抠出来。下面三个分镜都用
base R，示例文本是最小可复现写法，**不能代替正式编码表或临床规则**。

## 分镜 1：关键词识别

值班备注写得很随意，你只想先标出“像呼吸道感染”的行，方便人工复核。

``` r
notes <- c(
  "患者咳嗽发热三天，考虑上感",
  "复查血糖，调整胰岛素",
  "支气管炎伴咽痛，门诊随访",
  "骨折术后拆线"
)

# 多个关键词：用 | 表示“或”
kw_pattern <- "咳嗽|发热|上感|咽痛|支气管炎|肺炎|呼吸道"

hit <- grepl(kw_pattern, notes)
data.frame(notes, hit)
```

                           notes   hit
    1 患者咳嗽发热三天，考虑上感  TRUE
    2       复查血糖，调整胰岛素 FALSE
    3   支气管炎伴咽痛，门诊随访  TRUE
    4               骨折术后拆线 FALSE

`grepl()`
得到逻辑向量，可直接当筛选条件。关键词表会变，把词维护在字符向量里再用
`paste(collapse = "|")` 拼起来，比改正则正文更安全。

``` r
keywords <- c("咳嗽", "发热", "上感", "咽痛", "支气管炎", "肺炎", "呼吸道")
kw_pattern2 <- paste(keywords, collapse = "|")
identical(kw_pattern, kw_pattern2)
```

    [1] TRUE

## 分镜 2：ICD 识别呼吸道感染

编码比自由文本整齐，但仍是字符串。下面用一组演示编码，识别常见的
J00–J06、J09–J18、J20–J22（示意范围）。

``` r
icd <- c("J06.9", "J18.9", "J20.9", "J45.9", "A09", "U07.1", "J22")

# ^J 锁定以 J 开头；括号内用 | 列子范围
infect_icd <- "^J(0[0-6]|09|1[0-8]|2[0-2])(\\.|$)"

is_resp_infect <- grepl(infect_icd, icd)
data.frame(icd, is_resp_infect)
```

        icd is_resp_infect
    1 J06.9           TRUE
    2 J18.9           TRUE
    3 J20.9           TRUE
    4 J45.9          FALSE
    5   A09          FALSE
    6 U07.1          FALSE
    7   J22           TRUE

`J45.9`（哮喘）也是呼吸系统，但不在这段“感染”示意规则里，所以是
`FALSE`。真实项目必须以当前 ICD 版本和业务编码表为准；`U07.1`
等编码要单独纳入，不能指望一条正则包办。

## 分镜 3：从规则字符串里抠字段

规则有时整段写在配置里，例如
`FIELD=体温|OP=>=|VALUE=37.5|UNIT=C`。你要的是把字段名、运算符、阈值取出来，而不是靠
`substr` 数位置。

``` r
rules <- c(
  "FIELD=体温|OP=>=|VALUE=37.5|UNIT=C",
  "FIELD=血氧|OP=<|VALUE=93|UNIT=%"
)

rule_pat <- "^FIELD=([^|]+)\\|OP=([^|]+)\\|VALUE=([^|]+)\\|UNIT=([^|]+)$"
matched <- regmatches(rules, regexec(rule_pat, rules))

rule_df <- do.call(
  rbind,
  lapply(matched, function(x) {
    if (length(x) < 5) return(rep(NA_character_, 4))
    x[-1]
  })
)
colnames(rule_df) <- c("field", "op", "value", "unit")
rule_df
```

         field  op   value  unit
    [1,] "体温" ">=" "37.5" "C" 
    [2,] "血氧" "<"  "93"   "%" 

括号是捕获组：`([^|]+)` 表示“连续一段不含 `|` 的内容”。`regexec()`
定位，`regmatches()` 取出；`x[-1]` 丢掉整串匹配，只留四个字段。

三个分镜做的是同一类事：先写清文本规律，再让 R
批量判断或提取。关键词表、ICD
范围、规则模板都会变，把“可变的那部分”留在数据里，正则只负责结构。
