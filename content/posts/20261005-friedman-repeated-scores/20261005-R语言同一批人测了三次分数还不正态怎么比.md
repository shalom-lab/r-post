# R语言：同一批人测了三次，分数还不正态，怎么比？
RPost
2026-10-05

10 个病人，术前、术后 1 天、术后 7 天各打一次疼痛分（0 到
10）。要问的是三个时点差不差。人是同一批，分数又偏，很多人会先想到重复测量
ANOVA。

## 三次疼痛分：这几种常见比法先别用

下面两种做法都不对。

把三个时点当成三组不同的人，做 Kruskal-Wallis，或拿时点两两做独立样本 t
检验：同一个人的三行被当成无关样本，谁基线高、谁基线低，会混进时点比较里。

重复测量 ANOVA
认同一批人，但人少的时候，残差要大致正态。疼痛分经常是多数人挤在一起、少数人特别高。下面这
10 个人就是这样：编号 6 术后升到 10 和 9，其余人术后大多落在 3 到 5。

``` r
pain <- data.frame(
  id = factor(rep(1:10, times = 3)),
  time = factor(
    rep(c("术前", "术后1天", "术后7天"), each = 10),
    levels = c("术前", "术后1天", "术后7天")
  ),
  score = c(
    8, 7, 9, 8, 7, 6, 8, 9, 7, 8,
    4, 3, 5, 4, 3, 10, 4, 5, 3, 4,
    5, 3, 4, 4, 4, 9, 3, 5, 4, 3
  )
)
```

正态看残差：`lm(score ~ time + id)` 先扣掉时点和人的高低，再对残差做
Shapiro-Wilk。

``` r
shapiro.test(residuals(lm(score ~ time + id, data = pain)))
```

        Shapiro-Wilk normality test

    data:  residuals(lm(score ~ time + id, data = pain))
    W = 0.806, p-value = 8.448e-05

Shapiro-Wilk：W = 0.806，p = 8.448e-05。10 个人，残差偏成这样，重复测量
ANOVA 的正态假设站不住。

Friedman
检验按每个人内部的三次评分排名，比名次。不要求残差正态，也不要求球形。人与人之间仍要独立：张三的分数不要由李四决定。

## 用 friedman.test() 检验：评分 ~ 时点 \| 编号

公式 `score ~ time | id`：左边是评分，`time`
是要比较的时点，竖线后面是人的编号。Base R 自带，不用加包。

``` r
friedman.test(score ~ time | id, data = pain)
```

        Friedman rank sum test

    data:  score and time and id
    Friedman chi-squared = 10.432, df = 2, p-value = 0.005428

Friedman chi-squared = 10.432，df = 2，p =
0.005428。三个时点的评分不全相同。df 是时点数减
1。检验到此为止：至少有一个时点和另外的不同，哪一对还要往下看。

表如果还是宽的（一行一个人，三列分数），直接把这三列变成矩阵交给
`friedman.test()`，行是人、列是时点。这里手上是长表，用 `unstack()` 按
`time` 把 `score` 摊成宽表，每人一行、三个时点各一列，先看一眼形状：

``` r
head(as.matrix(unstack(pain, score ~ time)))
```

         术前 术后1天 术后7天
    [1,]    8       4       5
    [2,]    7       3       3
    [3,]    9       5       4
    [4,]    8       4       4
    [5,]    7       3       4

``` r
friedman.test(as.matrix(unstack(pain, score ~ time)))
```

        Friedman rank sum test

    data:  as.matrix(unstack(pain, score ~ time))
    Friedman chi-squared = 10.432, df = 2, p-value = 0.005428

结果和长表写法一样，chi-squared =
10.432。自己的数据本来就是宽表时，把三列分数取出来 `as.matrix()`
即可。宽表怎么转成长表，另有一篇，不在这里重讲。

坑：有人缺一次随访时，`friedman.test()` 会报
`not an unreplicated complete block design`。下面临时把编号 1
的术前分改成 `NA`，演示完再改回 8，后面的两两比较仍用完整数据。

``` r
pain$score[pain$id == 1 & pain$time == "术前"] <- NA
friedman.test(
  score ~ time | id,
  data = droplevels(subset(pain, ave(!is.na(score), id, FUN = all)))
)
```

        Friedman rank sum test

    data:  score and time and id
    Friedman chi-squared = 9.1515, df = 2, p-value = 0.0103

``` r
friedman.test(na.omit(as.matrix(unstack(pain, score ~ time))))
```

        Friedman rank sum test

    data:  na.omit(as.matrix(unstack(pain, score ~ time)))
    Friedman chi-squared = 9.1515, df = 2, p-value = 0.0103

``` r
pain$score[pain$id == 1 & pain$time == "术前"] <- 8 # 还原成原值
```

两种写法都只留三个时点齐全的 9 个人，chi-squared = 9.1515，p =
0.0103。长表写法里，`ave(!is.na(score), id, FUN = all)`
给每一行标出「这个人三次都有分」，`subset()` 只留这些人。还要套一层
`droplevels()`：编号 1 的行删掉了，`id` 的因子水平里还留着
1，不去掉仍会报同样的错。宽表写法里，`na.omit()` 直接删掉带 `NA`
的那一行。

## 整体有差异后，两两比并校正 p 值

整体显著之后，用配对 Wilcoxon 把时点两两比，再用 Holm
校正这三次比较。仍是 Base R。

``` r
pairwise.wilcox.test(
  pain$score, pain$time,
  paired = TRUE,
  p.adjust.method = "holm"
)
```

        Pairwise comparisons using Wilcoxon signed rank exact test 

    data:  pain$score and pain$time 

            术前  术后1天
    术后1天 0.043 -      
    术后7天 0.029 1.000  

    P value adjustment method: holm 

校正后的 p：术前对术后 1 天 0.035，术前对术后 7 天 0.035，术后 1
天对术后 7 天 0.777。中位数从术前的 8 降到术后的 4，并停在 4。术后 1
天和术后 7 天，在这 10 个人里分不出差别。

坑有两个。`paired = TRUE` 按每个时点内部的行顺序配对，不认 `id`
这一列。三个时点里编号的先后必须一致；上面用 `rep(1:10, times = 3)`
排过，顺序是齐的。评分是整数，同分很多（统计上叫
ties），还有人两次分数相同，函数做不了精确检验，表头写的是 continuity
correction，也就是带连续性校正的渐近 p 值。

名次有多齐，可以看 Kendall 的 W：检验统计量除以「人数 ×（时点数 −
1）」。0 是大家内部的排序各排各的，1 是所有人把三个时点排成同一个顺序。

``` r
unname(friedman.test(score ~ time | id, data = pain)$statistic) / (10 * 2)
```

    [1] 0.5216216

得到 0.5216216。10 个人里有 9
个人术前分最高，术后两次谁高谁低各人不一样，所以 W 落在 0.5
左右，算不上完全一致。

同一批人、三个及以上时点、分数又偏：`friedman.test(评分 ~ 时点 | 编号)`；整体有差异，再
`pairwise.wilcox.test(..., paired = TRUE)`，并校正 p 值。
