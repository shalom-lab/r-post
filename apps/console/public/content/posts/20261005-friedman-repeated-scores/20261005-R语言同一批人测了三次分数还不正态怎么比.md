# R语言：同一批人测了三次，分数还不正态，怎么比？
RPost
2026-10-05

10 个病人，术前、术后 1 天、术后 7 天各打一次疼痛分（0 到
10）。要问的是三个时点差不差。人是同一批，分数又偏，重复测量 ANOVA
常常被先拿出来。

## 三次疼痛分，重复测量 ANOVA 先别急着上

两条常见的旧路都别直接用。

把三个时点当成三组不同的人，做 Kruskal-Wallis，或拿时点两两做独立样本 t
检验：同一个人的三行被当成无关样本，谁基线高、谁基线低，会混进时点比较里。

重复测量 ANOVA
认同一批人，但人少的时候，残差要大致正态。疼痛分经常是多数人挤在一起、少数人特别高。下面这
10 个人就是这样：编号 6 术后爆到 10 和 9，其余人术后大多落在 3 到 5。

``` r
pain <- data.frame(
  id = factor(rep(1:10, times = 3)),
  time = factor(
    rep(c("术前", "术后1天", "术后7天"), each = 10),
    levels = c("术前", "术后1天", "术后7天")
  ),
  score = c(
    8, 7, 9, 8, 7, 6, 8, 9, 7, 8,
    4, 3, 5, 4, 3, 10, 4, 5, 3, 4,
    5, 3, 4, 4, 4, 9, 3, 5, 4, 3
  )
)
```

正态看残差：`lm(score ~ time + id)` 先扣掉时点和人的高低，再对残差做
Shapiro-Wilk。

``` r
shapiro.test(residuals(lm(score ~ time + id, data = pain)))
```

        Shapiro-Wilk normality test

    data:  residuals(lm(score ~ time + id, data = pain))
    W = 0.806, p-value = 8.448e-05

Shapiro-Wilk：W = 0.806，p = 8.448e-05。10 个人，残差偏成这样，重复测量
ANOVA 的正态假设站不住。

Friedman
检验按每个人内部的三次评分排名，比名次。不要求残差正态，也不要求球形。人与人之间仍要独立：张三的分数不要由李四决定。

## 长表一行 friedman.test：评分 ~ 时间 \| 编号

公式 `score ~ time | id`：左边是评分，`time`
是要比较的时点，竖线后面是人的编号。Base R 自带，不用加包。

``` r
friedman.test(score ~ time | id, data = pain)
```

        Friedman rank sum test

    data:  score and time and id
    Friedman chi-squared = 10.432, df = 2, p-value = 0.005428

Friedman chi-squared = 10.432，df = 2，p =
0.005428。三个时点的评分并不一样。df 是时点数减
1。检验到此为止：至少有一个时点和另外的不同，哪一对还要往下看。

表如果还是宽的（一行一个人，三列分数），不必先转长表。把分数按列填进矩阵，行是人、列是时点，结果相同。这里的向量本来就是按术前、术后
1 天、术后 7 天各 10
个数堆好的，和矩阵按列填充的顺序一致。宽表怎么拧成长表，另有一篇，不在这里重讲。

``` r
friedman.test(matrix(
  pain$score,
  nrow = 10,
  dimnames = list(levels(pain$id), levels(pain$time))
))
```

        Friedman rank sum test

    data:  matrix(pain$score, nrow = 10, dimnames = list(levels(pain$id), levels(pain$time)))
    Friedman chi-squared = 10.432, df = 2, p-value = 0.005428

坑：有人缺一次随访时，空格子会让 `friedman.test()` 报
`not an unreplicated complete block design`。先只留三个时点都有分的编号，再检验。

## 整体有差异后，两两比并校正 p 值

整体显著之后，用配对 Wilcoxon 把时点两两比，再用 Holm
校正这三次比较。仍是 Base R。

``` r
pairwise.wilcox.test(
  pain$score, pain$time,
  paired = TRUE,
  p.adjust.method = "holm"
)
```

        Pairwise comparisons using Wilcoxon signed rank exact test 

    data:  pain$score and pain$time 

            术前  术后1天
    术后1天 0.043 -      
    术后7天 0.029 1.000  

    P value adjustment method: holm 

校正后的 p：术前对术后 1 天 0.035，术前对术后 7 天 0.035，术后 1
天对术后 7 天 0.777。中位数从术前的 8 降到术后的 4，并停在
4。术后这两天在这 10 个人里分不出来。

坑有两个。`paired = TRUE` 按每个时点内部的行顺序配对，不认 `id`
这一列。三个时点里编号的先后必须一致；上面用 `rep(1:10, times = 3)`
排过，顺序是齐的。评分是整数，结很多，还有人两次分数相同，函数做不了精确检验，表头写的是
continuity correction，也就是带连续性校正的渐近 p 值。

名次有多齐，可以看 Kendall 的 W：检验统计量除以「人数 ×（时点数 −
1）」。0 是大家内部的排序各排各的，1 是所有人把三个时点排成同一个顺序。

``` r
friedman.test(score ~ time | id, data = pain)$statistic / (10 * 2)
```

    Friedman chi-squared 
               0.5216216 

得到 0.5216216。

同一批人、三个及以上时点、分数又偏：`friedman.test(评分 ~ 时点 | 编号)`；整体有差异，再
`pairwise.wilcox.test(..., paired = TRUE)`，并校正 p 值。
